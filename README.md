# ETF 大类轮动策略（回测 + 每日信号）

根据财经视频《一条视频学会怎么实操ETF》中的策略复刻实现，用真实行情数据验证，并做了多项改进。

## 推荐配置（最终版）

```
标的池: 纳指ETF / 创业板ETF / 黄金ETF / 中概互联网ETF
涨幅窗口: 20日    均线: MA20    调仓: 每周    成本: 0.1%/次
溢价过滤: 场内价相对净值溢价 > 3% 的标的不可买入
Fed过滤:  美联储加息周期(13周美债较12个月前上升>0.25%)禁买创业板ETF
```

回测结果（2021-03-09 ~ 2026-08-01）：
- 累计 **+297.3%**，年化 **30.4%**，最大回撤 **-23.1%**
- 年度：2021 +3.5%、2022 +12.5%、2023 +27.0%、2024 +39.8%、2025 +72.0%、2026(至7月) +11.7%
- 换仓 112 次，在场时间 89.1%

## 美联储加息/降息因素（新增）

数据：Yahoo `^IRX`（13周美债收益率，紧贴美联储政策利率），`data/us3m_yield.csv`。
周期判定：13周美债较 **12个月前** 变化 > +0.25% = 加息期；< -0.25% = 降息期；否则中性。

各ETF平均周收益（2020-01 ~ 2026-07）：

| ETF | 加息期 | 降息期 | 中性期 |
|---|---|---|---|
| 纳指ETF | +0.14% | +0.41% | +0.40% |
| 创业板ETF | **-0.42%** | **+0.63%** | +0.42% |
| 黄金ETF | +0.29% | **+0.85%** | +0.03% |
| 中概互联网ETF | -0.06% | +0.24% | -0.11% |

结论：
- **创业板（A股成长）对美联储最敏感**：加息期每周平均 -0.42%，是明确的减分项；
- 黄金在降息期最强（+0.85%/周），动量系统会自动捕捉；
- 纳指意外抗加息（+0.14%/周），**加息期禁买纳指反而大幅降低收益**（+267.7%→+148.4%），不要照搬"成长股怕加息"的直觉。

Fed过滤效果（加息期禁买创业板，稳健性已验证：3/6/9/12月窗口、0.15/0.25/0.50阈值下均为正贡献）：

| 配置 | 累计 | 年化 | 最大回撤 |
|---|---|---|---|
| 基线（无Fed过滤） | +267.7% | 28.5% | -23.1% |
| +加息期禁买创业板 | +276.3% ~ +297.3% | 29.1% ~ 30.4% | -23.1% |
| 加息期禁买创业板+纳指 | +148.4% | 19.1% | -27.2% |

## 三项改进的效果对比（含成本, 每周, 20/20）

| 配置 | 累计 | 年化 | 最大回撤 | 换仓 |
|---|---|---|---|---|
| 基线 top1 | +193.0% | 23.0% | -27.5% | 110 |
| +top2 等权 | +120.6% | 16.5% | -19.2% | 151 |
| +止损 20% | +183.9% | 22.2% | -28.0% | 112 |
| +溢价≤3% | +267.7% | 28.5% | -23.1% | 114 |
| 三项全开 | +141.9% | 18.5% | -16.6% | 163 |

结论：溢价过滤收益/回撤双赢；top2 大幅降回撤但收益腰斩（求稳模式）；20%止损基本无效（MA20先触发）。

## 使用步骤

```bash
# 1. 更新数据（行情/原始价/净值/美债，需联网）
python fetch_data.py
python fetch_irx.py        # 下载13周美债收益率(仅需一次)

# 2. 一键: 回测摘要 + 最新信号(推荐)
python final.py

# 3. 回测(可加 --fed)
python backtest.py --codes 513100,159915,518880,513050 --freq weekly --ret 20 --ma 20 --premium 0.03 --fed hike_no_cyb

# 4. 对比/探索
python improve.py          # 三项改进对比
python improve_fed.py      # Fed过滤对比
python fed_sensitivity.py  # Fed参数稳健性
```

输出文件位于 `output/`。
